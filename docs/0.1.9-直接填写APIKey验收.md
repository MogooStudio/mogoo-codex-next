## 实现与使用

按用户要求撤回0.1.8的中转本地配置读取。中转连接完全由插件设置决定：填写 Responses API 基础地址、直接填写 API Key、选择独立模型并保存。删除本地连接模块和 next_local_config 工具，移除本地/手动模式选择、重新读取以及密钥环境变量名输入框。

API Key 使用密码输入框。Windows 后台使用当前账户 DPAPI 加密存入插件 config.json，公开设置不返回明文或密文，只返回是否可用。新 Key 保存后输入框清空，留空继续使用；填写新值替换，勾选清除后保存删除。地址变更需重新填写 Key，目录请求不会将已保存 Key 自动发往新地址。旧环境变量配置仅后台兼容，保存直接输入的新 Key 后替换旧来源。

读取模型目录使用未保存表单或同地址的已保存 Key，不保存表单、不推理。生成子进程只从专用环境变量取得 Key，命令行参数只含变量名。模型、low、服务档位、皮肤与仅追加草稿逻辑保留；未自动切换当前官方配置。

直接加密保存当前支持 Windows；其他系统明确返回不支持提示，不以明文方式降级保存。
