# 0.1.8 本地中转配置读取与验收

更新日期：2026-10-20。

## 实现内容

- 用户确认默认文件为 `~/.codex/config.toml`。中转连接新增“使用 Codex 本地配置（默认）”和“手动填写”；兼容已经保存的手动中转连接。
- 后台读取所选本地 provider 的地址与认证来源，支持环境变量、静态 API Key、自定义请求头，以及显式 API Key 认证使用的本地 auth.json。只读取 API Key 字段，不复用官方 ChatGPT OAuth token，不执行认证命令。
- 支持本地活动 profile；不选用未启用的中转 provider。不支持的协议、认证方式或缺少配置会给出明确固定提示，不回退到官方模型目录。
- 本地连接读取仅复用连接配置；建议模型、low 思考程度和服务档位仍由插件独立选择。本地模型名称只作参考，不自动覆盖插件模型。
- 新增只读 next_local_config 工具，前端仅取得连接元信息和认证是否可用，不取得真实密钥。读取目录及生成时由后台重新解析本地连接，不把 Key 保存到插件配置、工具参数或子进程命令行。
- 目录请求按本地连接 GET /models；本地配置变化会使建议配置指纹变化。手动模式保留 API 地址和密钥环境变量名。
- 本地 TOML 解析需要 Python 3.11+；Python 3.10 可继续使用手动模式。
