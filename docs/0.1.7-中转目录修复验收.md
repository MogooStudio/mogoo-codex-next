# 0.1.7 中转模型目录修复与验收

更新日期：2026-10-20。

## 修复内容

- 根因：前端读取目录时没有传递未保存表单的服务来源；服务端使用已保存配置，读取适配器又固定走官方 Codex 模型目录。
- 前端现发送当前来源、API 基础地址、密钥环境变量名或官方 CLI 路径，目录读取不保存表单。中转缺少地址或变量名时先提示补全，不请求官方目录。
- 中转由后台 GET API基础地址/models，实际密钥仅从选定环境变量读取；不接受实际密钥值参数，不回显远端响应或异常。请求设置10秒网络超时与1MB读取上限，不跟随重定向转发认证。
- 目录不支持、鉴权或网络失败时显示对应固定提示并保留手动输入，不回退官方目录。目录可读不代表模型可调用或支持建议生成所需的Responses API。
- 切换来源、地址或密钥变量名清空旧候选，迟到响应丢弃；保留手动输入的模型ID。目录读取期间轮询不会误启用重复读取按钮。
- 官方目录使用隔离只读CLI实例，结束后关闭，不替换当前聊天读取连接。
- 合并此前确认的开发者mogoo和标题“下一步建议／对话：”更新。
